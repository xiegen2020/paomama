跑马吗 · 隐私政策

本页面是「跑马吗」应用内「设置 → 隐私政策」入口指向的唯一正式文本。

跑马吗是一款完全离线的马拉松赛事查询应用。它不联网、不申请任何系统权限、没有账号，也不收集关于你的任何信息。

  • 不申请任何权限（包括网络、位置、通讯录、相机、麦克风、相册、通知）
  • 应用运行时不发起任何网络请求
  • 没有账号体系，没有服务端，没有数据上传
  • 不接入任何第三方 SDK、广告或统计组件

一、适用范围

本政策适用于「跑马吗」应用程序（开发者与版本信息见页尾）及其随包发布的全部内容。它不适用于任何第三方网站或服务——应用内展示的赛事来源链接指向第三方页面，访问这些页面时的行为由该第三方自己的政策约束。

二、我们收集的信息：不收集

跑马吗不收集、不接收、不存储、不传输任何可识别到个人的信息。逐项说明如下：

常见采集项本应用说明
设备标识符（OAID / UDID / 序列号等）不采集应用无任何标识符读取逻辑
地理位置不采集未申请位置权限，也无法读取定位
通讯录、通话记录、短信不采集未申请相关权限
相机、麦克风不采集未申请相关权限
相册、文件（读取）不采集应用不读取用户文件
通知权限不申请当前版本不提供任何消息推送或提醒功能
网络访问不申请见第四节
行为埋点 / 统计 / 崩溃上报无无任何上报通道
如果你希望核验以上说法：应用仅使用 HarmonyOS 提供的系统能力，未引入任何第三方运行时依赖；由于不申请网络权限，它在技术上也无法把数据发出去。

三、存在你设备上的数据

本应用唯一会写入的数据，是你主动操作产生的我的收藏：

  • 内容：你收藏的赛事编号列表。
  • 位置：仅存储在本机应用私有数据目录中（HarmonyOS 首选项 preferences，键名 favoriteIds）。
  • 去向：不上传、不同步、不共享，也不跨设备迁移。杀掉进程后仍然保留，卸载或更换设备后即消失。
  • 如何清除：在应用内取消收藏；或在系统「设置 → 应用 → 跑马吗 → 清除数据」一次性清空；卸载应用同样会清除。

除收藏之外，本应用不记录你的浏览历史、点击行为或搜索内容。

四、网络行为

跑马吗的赛事数据是随安装包一起发布的本地数据集，应用运行时不发起任何网络请求，也不声明网络访问权限。因此：

  • 不存在数据在公网上的传输，也不存在跨境数据传输；
  • 不存在服务端日志记录你的访问；
  • 离线状态与联网状态下，应用功能完全一致。

五、第三方 SDK 与共享

本应用不接入任何第三方 SDK、广告 SDK、统计或推送组件，不与任何第三方共享数据，也不存在数据买卖、租赁或交换行为。

六、赛事内容的来源与准确性

虽不采集你的信息，但我们有义务说明你看到的内容从哪来：

  • 赛事基础信息（名称、日期、地点、认证等级、竞赛项目、主办单位）来自中国田径协会官方赛事平台（runchina）公开的赛历接口，抓取后随包发布。
  • 报名、抽签、缴费、补录、领物、起终点等日程信息，赛历接口并不提供，我们逐场核对公开竞赛规程、报名公告与官方回顾稿后补入，并在应用内标注来源链接。查不到准确信息的一律留空，不用猜测值填充。
  • 赛历是快照：某一届临时取消或改期，官方接口不会回头修正。我们逐场核对时发现的不实记录，会在应用内以「赛历更正」如实标出并附出处。
  • 比赛线路：依次经过的路段与地点名逐场摘自公开原文；折线几何由 OpenStreetMap 数据生成。线路几何 © OpenStreetMap contributors（ODbL）。应用内展示的线路图是本地矢量示意图，只表示大致走向，不表示道路位置，也不是地图。
  • 赛事配图：应用内的赛事装饰性配图为 AI 生成的示意图，不代表任何真实赛事的现场照片，与具体赛事无对应关系。

以上信息仅供查询参考，报名与参赛请以组委会官方发布为准。因依据应用内信息作出决定而造成的后果，本应用不承担责任。

七、未成年人

本应用不采集任何个人信息，也不提供账号、社交、支付或内容发布功能，因此不存在面向未成年人的数据收集行为。马拉松路跑活动对参与者年龄与健康状况有要求，未成年人使用本应用查询信息建议在监护人指导下进行。

八、政策变更

如果未来版本引入任何需要联网、申请权限或采集信息的功能（例如赛事提醒），我们会先更新本政策并重新取得你的同意，再上线该功能。变更后的政策会在本页面公布，并在应用内「关于」中同步版本号与生效日期。
